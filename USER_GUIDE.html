Ceph Issue Intelligence KB

User Guide — Search known issues, workarounds, and fixes across JIRA, Ceph Tracker, and Red Hat KB

1. What is Ceph Issue Intelligence KB?

Ceph Issue Intelligence KB is an MCP server that indexes 14,600+ engineering issues from IBM Ceph JIRA and Red Hat Knowledge Base. It answers one question: "Has this problem been seen before?"

  • Search issues across all sources with one query
  • Check if an error is a known issue
  • Find workarounds and fixes for known problems
  • Match stacktraces and health warnings to existing issues
  • Track hot issues and component health

Ships pre-built and auto-updates. No manual data collection needed.

2. Connect Your Agent

Option A: Cursor (stdio)

{
  "mcpServers": {
    "ceph-issue-kb": {
      "command": "python3",
      "args": ["-m", "ceph_issue_kb.server.mcp_server"],
      "cwd": "/path/to/ceph-issue-kb"
    }
  }
}

Option B: HTTP/SSE (Bob, Claude Desktop, Continue, Cline)

python -m ceph_issue_kb.server.mcp_server --transport sse --host 0.0.0.0 --port 8083
{
  "mcpServers": {
    "ceph-issue-kb": {
      "url": "http://localhost:8083/sse",
      "transport": "sse"
    }
  }
}

7. Troubleshooting

  • No issues found — Try broader search terms. Use search_issues without component/version filters first.
  • Agent doesn't see the server — Restart the IDE after editing mcp.json.
  • SSE connection refused — Verify: curl http://localhost:8083/health.
  • Stale data — The KB auto-updates on startup. Restart the server to pull latest issues.
